# LumaCapture 0.1.0

Release preparation is in progress. This document is not a published-release announcement.

The implementation includes native desktop capture adapters, local HTTPS/WebRTC phone receiving, phone/screen/combined recording, pause and recovery, SQLite media indexing, validated compression, a Qt desktop interface, and an offline mobile camera page.

Consult VERIFICATION.md for actual platform/device results and remaining requirements. Publication is blocked until the release verification manifest contains evidence for each required gate.
