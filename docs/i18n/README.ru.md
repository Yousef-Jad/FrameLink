# FrameLink

Запись экрана и камеры телефона в локальной сети.

[English](../../README.md) | [العربية](README.ar.md) | [Русский](README.ru.md) | [简体中文](README.zh-CN.md)

FrameLink записывает экран, камеру телефона или оба источника. Компьютер получает видео из браузера телефона по зашифрованному соединению WebRTC, сохраняет записи локально и автоматически ставит экспорт в MP4 в очередь с последующей проверкой файлов. Облачная учётная запись не нужна.

![Настоящее окно FrameLink в режиме Phone с интерфейсом сопряжения](../assets/framelink-phone-pairing.png)

*Окно работающего приложения. Демонстрационный QR-код намеренно не позволяет подключиться и не содержит ключа сопряжения или адреса частной сети.*

## Возможности

- Захват экрана средствами Windows и Linux, включая Wayland/Hyprland через системный портал.
- Передача видео из Android Chrome и iPhone Safari; проверка на физических устройствах ещё не завершена.
- Одновременная запись экрана и камеры: «картинка в картинке» или отдельные синхронизированные файлы.
- Сопряжение по локальному Wi-Fi, управление записью и остановкой с телефона, запись микрофона.
- Автоматическое сжатие с проверкой экспорта; библиотека записей с размерами файлов и экономией места.

## Пример сжатия

![Слева — оригинал, справа — сжатая запись](../assets/compression-comparison.png)

**1,47 МБ → 0,81 МБ | экономия 45,2% места | H.264**

Реальная 30-секундная запись рабочего стола в 1920×1080 на одном и том же кадре (10,000 с). Увеличенные в 8× фрагменты демонстрируют сохранение мелких деталей шрифтов и тонкие эффекты сжатия DCT. Результаты сжатия с потерями зависят от сложности сцены и настроек. [Файлы, настройки и методика](../COMPRESSION_EVIDENCE.md).

Для будущих записей **Keep Original — сохранять оригинал** по умолчанию отключено: оригинал удаляется только после проверки целостности и выборочной оценки качества меньшего файла. Существующие записи защищены. [Политика хранения](../COMPRESSION_RETENTION.md).

## Установка

**Windows 10/11 x64:** распакуйте ZIP для Windows и запустите `FrameLink/FrameLink.exe`.

**Linux x86_64:** разрешите выполнение AppImage и запустите его либо распакуйте tar-архив и выполните `./FrameLink/FrameLink`. Для Wayland нужны PipeWire и работающий портал ScreenCast.

Готовые сборки для Windows и Linux доступны на странице [Releases](https://github.com/Yousef-Jad/FrameLink/releases). Для запуска из исходного кода используйте Python 3.12+ и [инструкции по сборке](../USER_GUIDE.md#build-from-source).

## Быстрый старт

1. Запустите FrameLink и выберите **Screen**, **Phone** или **Both**.
2. Для режима Phone подключите устройства к одной сети Wi-Fi или поддерживаемой точке доступа, настройте доверие к сертификату HTTPS, затем отсканируйте QR-код и разрешите доступ к камере.
3. Проверьте изображение, начните запись, остановите её и используйте проверенный сжатый файл из библиотеки.

## Подключение без интернета

Для локальной записи интернет не нужен. Однако устройства должны быть доступны по локальным адресам, сетевой экран должен разрешать трафик, а телефон — доверять сертификату компьютера. Изоляция клиентов точки доступа препятствует подключению.

На iPhone установите проверенный публичный корневой сертификат, затем включите полное доверие: **Настройки → Основные → Об этом устройстве → Доверие сертификатам**. Не обходите предупреждения Safari о сертификатах. [Настройка доверия и сети](../USER_GUIDE.md#first-time-certificate-trust-and-pairing).

## Совместимость и проверки

Целевые платформы — Windows 10/11 x64 и Linux x86_64. Есть результаты локальных испытаний записи экрана в Linux с X11 и Hyprland/Wayland. Передача видео и доверие сертификатам на физических Android/iPhone, пользовательское оборудование Windows, работа через точки доступа и длительная синхронизация звука с видео ещё требуют проверки. [Результаты и ограничения](../VERIFICATION.md).
