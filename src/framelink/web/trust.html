📱 iPhone / iPad Setup (Safari)

1
Download the configuration profile Tap below, then tap "Allow" when Safari asks to download.
Download iOS Trust Profile
2
Install the profile in Settings Open the iPhone Settings app → tap Profile Downloaded (near the top) → tap Install (enter your passcode).
3
Enable Full Root Trust (Crucial!) In Settings, go to: General → About → Certificate Trust Settings.
Under "ENABLE FULL TRUST FOR ROOT CERTIFICATES", toggle ON FrameLink Local CA.
4
Verify and open camera Open this only after enabling full trust. If Safari warns, stop; never choose Visit This Website. The page itself cannot detect a bypassed warning.
Test Secure Connection
⚠️ Why this is needed: iOS requires explicit user permission in Certificate Trust Settings for private local servers to access camera streams securely.
