Trust your desktop

This HTTP setup page cannot authenticate the desktop. Before installing anything, verify the certificate's SHA-256 fingerprint against the value displayed in FrameLink on your desktop. Prefer transferring the certificate by USB if you cannot inspect its fingerprint on your phone.

Installing a root CA grants it authority to authenticate websites on your phone. Install only your own desktop's certificate, keep its private key protected, and remove the trust when you stop using FrameLink. Never install a certificate from a stranger's QR code.

iPhone / iPad

  1. Download the certificate profile.
  2. Open Settings → General → VPN & Device Management, inspect the downloaded profile, and install it.
  3. Open Settings → General → About → Certificate Trust Settings. Enable full trust for this FrameLink Local CA.
  4. Scan a fresh HTTPS pairing QR code from the desktop. A certificate warning must no longer appear.

Android

  1. Download the root CA certificate.
  2. In Settings, search for “Install a certificate”, then select CA certificate. Paths vary by device. Review the system warning and inspect the certificate.
  3. Scan a fresh HTTPS pairing QR code and open it in Chrome.

This page does not request camera access. Camera access is requested only on the trusted HTTPS page after you press Connect camera. No internet connection is required. If trust cannot be established, do not bypass the browser's security warning.
